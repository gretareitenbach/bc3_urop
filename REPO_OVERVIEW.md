# Repository overview

This document summarizes what each file in this workspace does, based on the current code and data layout. Paths are relative to the repository root.

## Top-level scripts

- main.py
  - Primary end-to-end pipeline runner.
  - Loads global data and station inventory, processes each station, runs regression, generates plots, saves station summary CSV, and builds the final interactive map.

- test_pipeline.py
  - Test-mode pipeline runner.
  - Same flow as main.py, but includes safety checks for input files and samples 5 random stations when inventory is large.

- add_climatological_features.py
  - Post-processing step that adds climatology features to output/station_data.csv.
  - Computes climo_temp using station data and climo_humidity from a gridded humidity file (grid_10min_reh.dat).
  - Overwrites output/station_data.csv with added columns.

- requirements.txt
  - Python runtime dependencies used across the project.

- .gitignore
  - Ignores data/ and output/ directories.

## Package: climate_analysis/

- climate_analysis/__init__.py
  - Empty; marks the directory as a Python package.

- climate_analysis/data_loader.py
  - All parsing and data loading routines.
  - Reads global anomaly file, station inventory, and station-level TAVG data from GHCN-M formatted files.

- climate_analysis/analysis.py
  - Scientific and statistical analysis utilities.
  - Merges station and global data, computes anomalies, performs linear regression, and provides trend and distance helpers.

- climate_analysis/plotting.py
  - Generates diagnostic plots (regression, residuals, and time series) using a non-interactive Matplotlib backend.
  - Saves plots into output/plots/<StationID>/.

- climate_analysis/mapping.py
  - Builds the interactive Folium map.
  - Colors stations by slope and inserts plot links and metadata into popups.


## Multilinear analysis: multilinear/

- multilinear/spatial_analysis.py
  - Runs OLS regression (statsmodels) to explain station slope using climo_temp and climo_humidity.
  - Writes a coefficients/summary CSV (output/spatial_analysis_simple.csv).

- multilinear/slope_comparison.py
  - Uses regression coefficients to compute predicted slopes and residuals.
  - Writes a comparison CSV and generates two plots: actual vs predicted, and a spatial residual map.

## Data files: data/

These are local data assets used by the scripts. The folder is ignored by git.

- data/global_temps.txt
  - NASA/GISTEMP annual anomaly text file, read by climate_analysis/data_loader.py.

- data/ghcnm.tavg.v4.0.1.20260224.qcf.inv
  - GHCN-M station inventory metadata (IDs, lat, lon, elevation, name).

- data/ghcnm.tavg.v4.0.1.20260224.qcf.dat
  - GHCN-M station monthly TAVG records used to compute annual station averages.

- data/PatternScalingCoefficients_tas_ssp245-ssp370__r240x120.nc
  - NetCDF file with model slope coefficients (currently unused).

- data/grid_10min_reh.dat
  - Expected gridded humidity climatology (not present in this workspace, but required by add_climatological_features.py).

## Outputs: output/

These are generated artifacts and are ignored by git.

- output/station_data.csv
  - Main station summary table with metadata, regression stats, and plot links.
  - May be augmented with model_slope, climo_temp, and climo_humidity by post-processing scripts.

- output/world_climate_map.html
  - Interactive Folium map with station markers and plot popups.

- output/plots/<StationID>/
  - Regression, residual, and time-series images per station.

- output/multilinear/
  - Plots generated by multilinear/slope_comparison.py (actual vs predicted and residual map).

## Environment: .venv/

- Local Python virtual environment (not part of the source). Contains installed packages and should not be committed.
